# Крошки — домашняя книга рецептов

Небольшая адаптивная коллекция рецептов: ищите блюда, фильтруйте их по разделу, времени и сложности, сохраняйте любимые и добавляйте свои.

**Сайт:** [gina-eifman.github.io/crumbs](https://gina-eifman.github.io/crumbs/)

## Возможности

- Поиск по названию и ингредиентам, фильтры по категории, времени и сложности.
- Карточки с подробным просмотром ингредиентов и шагов приготовления.
- Избранное и форма добавления рецептов с проверкой полей.
- Автоматическое сохранение черновика формы в текущей вкладке.
- Адаптивная вёрстка для телефона и компьютера.

## Запуск

Откройте `index.html` через локальный веб-сервер, например расширение Live Server в VS Code. Скрипт загружает начальные данные из `recipes.json` как ES-модуль, поэтому открытие файла напрямую может не сработать.

Рецепты, добавленные через форму, и избранное хранятся в `localStorage` браузера. Черновик хранится в `sessionStorage` текущей вкладки.

## Технологии

HTML, CSS и JavaScript (ES-модули). Без фреймворков.
